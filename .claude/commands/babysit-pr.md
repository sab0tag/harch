# Довести PR #$ARGUMENTS до зелёного

**Цель.** PR #$ARGUMENTS в `sab0tag/harch`: CI зелёный на последнем коммите, нет конфликта с `main`,
нет неотвеченных замечаний ревью.

**Каждый проход:** состояние PR (merge state, check runs последнего коммита, ветки ревью).
- конфликт → влить `main` в ветку PR (merge, не rebase), прогнать тесты, запушить;
- красный `pytest` → найти причину, исправить, прогнать затронутые тесты локально, запушить;
- замечание ревью → небольшое — сделать, крупное — описать владельцу и ждать.

**Готово, когда** всё зелёное → одно сообщение владельцу «PR готов к слиянию» и остановить луп.

**Никогда:** сливать PR без явного «+» владельца; отключать/пропускать тесты; пустые коммиты для перезапуска CI;
force-push.

**Бюджет:** если тот же тест падает после двух попыток исправления — остановиться и описать проблему.
