# Статус проєкту

**Цель.** `docs/05_sprints.md` отражает то, что реально влито в `main`, а владелец проекта раз в неделю видит,
что блокирует работу со стороны больницы.

**Как.**
1. Влитые за 7 дней PR: `gh api "repos/sab0tag/harch/pulls?state=closed&base=main&per_page=50"` → `merged_at`
   за последние 7 дней (или GitHub MCP). Для каждого — номер, заголовок, тикет (S7-02, AI-10 …) из заголовка/коммитов.
2. Сверить с `docs/05_sprints.md`: тикет сделан, а статус не ✅ / нет ссылки на PR → поправить строку статуса.
3. Блокеры от больницы: пункты `⏳`/«ждём»/«чекаємо» в `docs/05_sprints.md` и открытые вопросы в
   `docs/09_discovery.md`.

**Готово, когда:**
- если статусы разошлись — ветка `docs/status-<дата>`, правка только `docs/05_sprints.md`, PR в `main`
  (коммит `docs: sprint status <дата>`); если не разошлись — без PR;
- открытый issue с заголовком «Чекаємо від лікарні» (создать один раз, если нет) — тело переписано:
  список того, что ждём, по-украински, коротко, каждому пункту — что именно прислать и зачем
  (без технических терминов: его пересылают дієтсестрі). Внизу — дата обновления.

**Никогда:** код и миграции; новый issue каждую неделю (только редактировать тот же); закрывать чужие issue;
слияние PR; персональные данные пациентов.

**Отчёт (последнее сообщение, уходит на почту), українською, до 12 рядків:**
«За тиждень злито: N PR — …» (3–5 главных), «Документація: ✅ збігається / PR <ссылка>»,
«Чекаємо від лікарні: <коротко> — <ссылка на issue>».
