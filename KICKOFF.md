# Первый промпт для Claude Code

Скопируй содержимое этого пакета в корень `harch/`, открой там Claude Code и отправь:

---

Прочитай CLAUDE.md и все файлы в docs/. Затем:

1. Перескажи в 10 строках, как ты понял домен и главные инварианты — чтобы я проверил, что мы
   поняли одинаково. Задай вопросы, если что-то в docs противоречит друг другу.
2. Выполни Sprint 0 (S0-01, S0-02, S0-03) из docs/05_sprints.md. Каждый тикет — отдельный
   коммит с ID в сообщении. После каждого тикета запускай тесты.
3. Остановись после S0-03 и покажи: как запустить, скриншот/описание сайдбара под каждой ролью,
   результат pytest.

Не начинай Sprint 1 без моего подтверждения.
