# 04. Интерфейс

## Каркас

- Слева — фиксированный сайдбар (240px) с навигацией по роли; на экранах < 992px сворачивается в offcanvas по кнопке-бургеру.
- Сверху — шапка: название закладу, дата «сьогодні», колокольчик уведомлений со счётчиком, меню пользователя (ПІБ, роль, вихід).
- Справа — контент: заголовок страницы + хлебные крошки, затем карточки/таблицы.
- Bootstrap 5 + Bootstrap Icons, без кастомной сборки. Крупные кнопки и шрифт ≥ 15px — пользователи 40–60 лет, часто с телефона.
- Статусы задач — единые бейджи: Очікує (серый), В роботі (синий), На перевірці (жёлтый), Затверджено (зелёный), Повернуто (красный), Прострочено (красная рамка).
- Все формы — HTMX: сохранение без перезагрузки, ошибки валидации inline.
- Печать: у меню-розкладки и розходу — `?print=1` → print-стили A4 + кнопка PDF (WeasyPrint).

## Ключевые экраны

### 1. Головна дієтсестри
- Шкала дня D+1: «Замовлення: 11/15 подано» с прогресс-баром; список неподавших відділень с кнопкой «Нагадати».
- Карточки по дієтам: дієта · порцій · выбранное меню · ккал vs норма.
- Блок «Мені перевірити» (последние 5 задач).

### 2. Замовлення відділення (dept_nurse) — самый важный экран для мобильного
- Дата обслуговування (по умолчанию завтра), відділення (фиксировано).
- Таблица дієт: код + название, поле «порцій» (numeric keypad, `inputmode="numeric"`), по умолчанию строка default_diet сверху.
- Итого внизу. Поле «Примітка».
- Кнопки: «Зберегти чернетку», «Подати на перевірку».
- Если задача rejected — красный алерт с комментарием дієтсестри над формой.
- Цель: подача с телефона ≤ 1 минуты.

### 3. Зведення замовлень (dietician)
- Матрица: строки — відділення, колонки — дієти, ячейки — порції; статус каждого замовлення бейджем.
- Итог по колонкам = порції по дієтам на день.
- Массовые действия: «Затвердити всі подані», по строке — затвердити / повернути з коментарем (модалка).

### 4. План меню на день (dietician)
- Для каждой дієти с порціями > 0 — select меню (только меню этой дієти, с поиском по номеру).
- Рядом: состав меню по прийомам їжі (свёрнуто), расчётные Б/Ж/В/ккал на человека vs норма (зелёный/жёлтый/красный).
- Кнопка «Показати розхід» — HTMX-предпросмотр суммарного розходу без сохранения.
- «Подати на перевірку» → задача шеф-кухарю.

### 5. Сьогодні на кухні (chef)
- По прийомам їжі: страва → сколько порций в разрезе дієт → итого порций, вихід.
- Клик по страве — картка-розкладка, пересчитанная на нужное число порций (брутто/нетто × N).
- Таблица «Факт»: продукт · план · факт · причина отклонения. Подать → дієтсестре.

### 6. Розхід продуктів (всі, кому доступно)
- Фильтр: дата или период. Группировка: по продукту (для складу) / по дієті / по страві.
- Колонки: продукт, брутто г, брутто кг, нетто г, ціна/кг, сума.
- Экспорт XLSX и PDF. Источник для утверждённых дат — только снапшот.

### 7. Списання (accountant)
- Дата → таблица из снапшота + отклонения из «Факт» → итоговое количество к списанию, сумма по ценам.
- Подать → дієтсестре на звірку.

### 8. Картка-розкладка (довідник)
- Шапка: № картки, назва, категорія, вихід, дієти (чипсы), бейдж «Не перевірено».
- Таблица інгредієнтів: продукт (autocomplete), брутто, нетто, % втрат (авто), Б/Ж/В/ккал (авто).
- Итог на порцию. Вкладка «Історія змін» (simple-history).
- Кнопка «Позначити як перевірено» (dietician).

### 9. Звіти (v0.1 — минимум)
- Меню-розкладка за дату (печатная форма с блоком підписів: Затверджую / Головний лікар, Лікар-дієтолог, Бухгалтер, Завідувач виробництва).
- Розхід за період по продуктах.
- Меню-вимога на день за типовою формою З-4а — XLSX (S4-05).
- Накопичувальна відомість за місяць за типовою формою З-13 (продукт × дні, кг, ціна, сума) — XLSX.
